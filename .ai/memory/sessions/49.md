# Request

用户要求彻底扫描当前仓库，报告所有疑似人名、地名以及能够关联或定位现实世界的资料，随后统一模糊化。此前要求同样适用于本次修改：代码和文档中不得保留实际隐私信息，包括真实网络名称。

# Scope and status

Status: in progress. 扫描当前工作区的 tracked、untracked 和隐藏项目文件，覆盖代码、文档、配置、脚本、测试及会话记录；依赖目录、构建产物和版本控制内部数据不作为内容编辑对象。不得为清理当前文件而擅自重写提交历史或执行推送。

# Investigation

待建立完整文件清单并分类核实。真实身份、网络、主机、位置、账号、联系方式和内部命名将与公开协议标识、通用技术术语及明确虚构的测试占位符区分。扫描命中的具体敏感值只用于核对，不回写到本会话记录。

# Plan

1. 盘点仓库文件、现有未提交修改和可能包含现实资料的文件类型。
2. 通过标识符、网络名称、主机与域名、地址、账号、联系方式、个人元数据及路径模式进行多轮扫描，并逐条阅读上下文。
3. 将确认或疑似的现实资料替换为一致、明显虚构且不影响功能的占位符；保留公开标准、第三方库和通用技术概念。
4. 对残留进行反向搜索，检查生成文件与源文件是否同步，运行必要的格式、测试、类型或构建验证。
5. 回写修改文件、替换类别、验证命令与结果，以及历史提交和运行时数据等剩余盲区。
